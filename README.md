# ❄️ 서울 첫눈 알리미

30년(1996~2025) 서울 기상 관측 데이터를 분석해 **첫눈이 오는 조건**을 찾고,
기상청 예보와 결합해 **"내일 첫눈이 올까?"**를 알려주는 서비스입니다.

> 🚧 개발 중. 2026년 11~12월 첫눈 시즌에 실제 운영하고 결과를 이 문서에 기록할 예정입니다.

## 왜 만들었나

기상청 예보는 "내일 눈/비"를 알려주지만, **"올해 첫눈"**에 대한 정보는 없습니다.

| 기상청 예보 | 첫눈 알리미 |
|---|---|
| 내일 눈/비 예보 | 올해 첫눈이 아직 안 왔는지 추적 |
| 강수확률 60% | 30년 관측 기반 **"첫눈일 확률"** |
| - | "평년(11/20)보다 5일 늦은 첫눈" 같은 역사적 맥락 |
| - | 첫눈 가능성이 생기면 알림 |

## 분석으로 알게 된 것

### 1. 첫눈 날짜를 몇 주 전에 미리 예측하기는 어렵다
- 서울 첫눈은 평균 **11월 20일**, 해마다 ±9.5일 차이
- 10월까지의 가을 기온은 첫눈 날짜와 거의 관계없음 (상관계수 약 ±0.1)
- 첫눈은 서서히 추워져서가 아니라 **며칠짜리 짧은 한파**가 들어온 날 온다 (첫눈 3일 전부터 평균기온이 약 5°C 급락)

### 2. 대신 "눈이 오는 조건"은 뚜렷하다
강수가 있는 날 중 눈일 확률이 50%가 되는 기온 (10~12월):

| 기준 | 눈 확률 50% |
|---|---|
| 최저기온 | 약 -1°C |
| 평균기온 | 약 2.4°C |
| 최고기온 | 약 6°C |

- **최저기온 2°C 이하는 눈의 필수 조건에 가깝다**: 눈 온 날의 99%가 만족했고, 이 조건을 만족하기 전에 첫눈이 온 해는 30년 중 한 번도 없음
- 눈 오는 날은 **차고 건조한 북서풍 공기**가 들어온 날 (이슬점 -7°C vs 비 5°C, 북서풍 58% vs 37%)

### 3. 첫눈은 "경계에 있는 사건"이다
- 일별 데이터로 만든 비/눈 판별 모델은 강수일 전체에서 정확도 90%지만, **첫눈은 10번 중 5번만** 맞혔다
- 놓친 첫눈은 모두 **새벽에 잠깐 눈이 오고 낮에는 풀린 날** → 하루 평균으로는 잡을 수 없다
- → 시간별 데이터로 모델을 개선 중
